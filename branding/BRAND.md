# Prettier Plugin for Flix · Brand guide

Use **Prettier Plugin for Flix** as the display name and `prettier-plugin-flix` as the npm package name. The artwork identifies this Prettier plugin. Use the full display name wherever the artwork appears alongside Flix or Prettier to make the project affiliation clear.

## Logo and colors

The logo is an italic white **F** built from staggered code lines on a rounded red tile. Use [logo.svg](logo.svg) as the master mark. Keep the artwork square and reserve at least one eighth of the tile width on each side when placing it next to other marks or text.

| Color | Hex | Use |
| --- | --- | --- |
| Red | `#C8102E` | The tile in the supplied artwork and its icon variants |
| White | `#FFFFFF` | Code lines and the small F |
| Warm white | `#FBF7F5` | Banner background and social title |
| Plum | `#211820` | Social card background |
| Dark ink | `#241A21` | Banner title |
| Muted ink | `#66565E` | Banner description |
| Pale rose | `#E5D0D9` | Social description |

The banner and social card use DejaVu Sans Bold for the name and DejaVu Sans Regular for the description. The SVGs contain outlined lettering for consistent rendering across systems.

## Design directions

| Direction | Rating | Assessment |
| --- | --- | --- |
| **Original mark with light and dark layouts** | **9/10** | Implemented here. The red tile stays recognizable across the README, social cards and browser tabs. The simplified favicon remains legible at 16 px. |
| **A red background throughout** | **7/10** | Strong visual presence for a launch announcement. A full-width red banner would dominate a documentation page. |
| **A multicolor code-line pattern** | **6/10** | More visibly references Prettier's color palette. The small icon would need a separate, simpler treatment, and the mark would sit closer to Prettier's visual identity. |
