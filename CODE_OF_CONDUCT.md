# Code of conduct

Treat contributors with respect in this project's issues, pull requests and other project spaces. Focus criticism on the work, explain disagreements constructively and respect people with different experience or backgrounds.

Harassment, discriminatory language, threats, and sharing someone else's private information without permission are unacceptable.

Project maintainers may remove content, restrict participation or block accounts when needed to enforce these standards. To report abuse or harassment privately, use [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
